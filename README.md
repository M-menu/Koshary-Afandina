# منيو QR عربي - كشري وحلواني أفندينا

منيو ويب متجاوب باللغة العربية مصمم بهوية **كشري وحلواني أفندينا** (الأصفر الذهبي والأحمر والورقي)، مع تصنيفات وبحث وسلة طلبات وإرسال الطلب مباشرة عبر واتساب.

## الملفات المرفقة
- `index.html`: هيكل الصفحة.
- `style.css`: التصميم والألوان المستوحاة من هوية أفندينا.
- `menu-data.js`: بيانات المطعم، الفروع، أرقام التوصيل، وجميع الأقسام والأصناف والأسعار.
- `app.js`: منطق البحث، الفلترة، خيارات الأحجام/الإضافات، وحساب السلة وإرسالها على واتساب.
